EXPERIMENT PARAMETERS
SLATE -- Spectral Latent Analysis & Trajectory Exploration
1. What are the tiny dots? Each tiny dot represents one single hour of the neural network's internal hidden memory state (h_t). Instead of keeping the AI memory hidden inside a black box, we capture every hour's state vector.
2. What is QR Projection (2D and 3D)? The network memory lives in 8 dimensions, which human eyes cannot see. QR decomposition finds the 2 or 3 most informative perpendicular directions and projects the 8D states into 2D/3D dots without distorting the trajectory.
3. What is the Linear Surrogate (Matrix A)? The neural network uses a non-linear tanh function. We use Least Squares to find a simple linear matrix A such that h_(t+1) approx A @ h_t. This linear approximation achieves over 84% accuracy, proving that local neural dynamics can be understood with standard linear algebra.
4. What does the Stability Circle mean? We calculate the eigenvalues of matrix A. If all eigenvalues lie inside the dashed unit circle (|lambda| < 1), the memory is mathematically stable: perturbations decay and never blow up. If any eigenvalue crosses outside (|lambda| > 1), the memory becomes explosive.
5. What is RREF? Reduced Row Echelon Form (computed via SymPy) checks whether any of the 8 hidden neurons are duplicates of each other. Pivot columns identify unique dimensions; free columns identify redundant ones.
